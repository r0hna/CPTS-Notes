# Sharp-View (power-view alternative)
#### Get users info help 
```
.\SharpView.exe Get-DomainUser -Help
```
#### Get specific user info 
```
.\sharview.exe -Get-DomainUser -Identity forend
```

snaffler.exe -s -d inlanefreight.local -o snaffler.log -v data
